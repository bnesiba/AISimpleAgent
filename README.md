Simple, extendable, ready-to-use langgraph-based AI agent.    
Examples of tools, metadata, streaming, and other features are provided to demonstrate how they can be used. 

The `codebase-reader` branch contains a prototype coding agent built to understand and update its own and other code.   
This agent was able to move through a codebase (it's own by default), understand and update files, and verify functionality.
